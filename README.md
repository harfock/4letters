# 成語圖譜・縱橫解字

繁體中文成語縱橫解謎遊戲。棋盤會以靜態資料預先編排，並在發佈前驗證交叉字元及成語連通性；遊戲不應在玩家開局時隨機重排棋盤。

## 詞庫規則

- 以教育部《成語典》下載資料為候選來源。
- 只取「主條成語／非主條成語」欄標示為「主條成語」的四字詞目。
- 對釋義開頭明確使用「即『X』。見『X』條」的非主條轉引形式，以主條詞目為準。例如保留「紙醉金迷」，排除「金迷紙醉」。
- 不將官方釋義、例句、書證或典源原文直接打包進遊戲；遊戲提示應另行撰寫。
- 來源及版本資訊：教育部《成語典》下載頁 https://language.moe.gov.tw/001/Upload/Files/site_content/M0001/respub/dict_idiomsdict_download.html ，資料版本 `dict_idioms_2020_20260929`。下載頁列有資料授權條款，使用或再散布前請遵守該條款及署名要求。

## 建立候選詞庫

需要 Python 3 及 openpyxl。將官方 XLSX 放在專案根目錄，執行：

```bash
python -m pip install openpyxl
python tools/filter_idioms.py dict_idioms_2020_20260929.xlsx data/idioms.json
```

輸出只含詞目與拼音，不含官方釋義。棋盤資料與提示須另行產生並通過驗證。

## 棋盤資料驗證\n\n預先編排棋盤後，將 21 關放在 `data/levels.json`，使用下列命令驗證：\n\n\`\`\`bash\npython tools/validate_levels.py data/levels.json\n\`\`\`\n\n驗證器會檢查關卡數、420 個擺放位置、每關 10–30 個成語、重複詞、交叉字元衝突、同方向重疊，以及交叉圖是否連通。\n\n## 開發驗收標準

- 21 關；每關 10 至 30 個成語，總計 420 個擺放位置。
- 每關所有成語都在同一個交叉連通圖內，不得有孤立詞目。
- 每個交叉位置的中文字必須一致；避免兩個詞只相鄰但沒有真正交叉。
- 棋盤、線索、初始揭示字及解鎖路徑均以靜態資料儲存，不在玩家開局時臨時生成。
- 進度、每關用時、總用時及已完成成語數可在本機保存；重玩不得重複計算已完成數。
